# Python Practice — ECS First-Year Exercises

A small collection of Python exercises I wrote during my first year studying Electronics & Computer Science. This was my place to doodle with code, try out class concepts, and learn by making simple programs.

The files are kept as an honest snapshot of that learning stage, so examples may be short or unfinished.

## What’s inside

The numbered `*exp.py` scripts explore:

- Basic input, output, and arithmetic
- Lists, tuples, sets, and dictionaries
- Loops, patterns, and functions
- Simple calculators and salary calculations
- Reading text files and finding words
- Exception handling and debugging with `pdb`
- Regular expressions for basic data validation and extraction
- NumPy arrays and introductory statistics
- Reading tabular data with pandas and plotting with Matplotlib

## Running an exercise

Use Python 3 and run a script from this repository:

```bash
python 1exp.py
```

Some examples read local files such as `sample.txt`, `data.txt`, or `data.csv`. The NumPy exercise needs NumPy; the pandas and plotting exercise needs pandas and Matplotlib.

## About

These are early learning exercises, not polished packages. I’m keeping them as a record of where my Python practice began and how it developed.
